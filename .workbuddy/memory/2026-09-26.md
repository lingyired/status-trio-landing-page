### 这轮修掉的坑：脚本匿名 curl 恒 403

脚本原先直接匿名打 `api.github.com`，本轮报 `curl: (56) ... error: 403`；挂代理也是 403
（出口 IP 被限流）。改成**优先 `gh api`（已登录，5000/h）、拿不到才回退 curl**，
gh 不在 PATH 时脚本自己认 `/opt/homebrew/bin/gh`。改完重跑输出 11 条，与手工落盘的内容 diff 一致。

顺带：**DMG 直连下载会长时间 0 字节**（不是 404，是慢）→ 加 `-x http://127.0.0.1:10808`
走本地代理，5 MB 约 2 s。以后取产物别再傻等直连。
