# 2026-09-21

## 调研：两个网盘有没有「下载次数」统计 API

ling 问「这两个网盘是否有统计下载次数的 api」。结论：**都没有可用的**，已写进 skill
`release-netdisk-mirror` 的 **§8**（含实测证据与探测方法备忘），这里只留要点：

- **夸克**：官方开放平台接口面固定（`/open/v1/share/*` 只有 detail / page_detail / search /
  saveas / saved stoken / update_list / inc_update_files），**无统计接口**。但 `share/detail`
  （→ 内部 `POST /1/clouddrive/share/sharepage/v2/detail`）返回的 `share_info` 里**带**
  `click_pv` / `save_pv` / `download_pv` / `visit_user_count`，CLI 的 JSON 结果里能读到；
  实测（三方 token）`is_owner:0` / `click_pv:-1` / 其余 0 → **值拿不到**。
- **百度**：`bdpan` 走 xpan，接口面只有 `share/{set,list,taskquery,transfer,verify}`，
  结构体 json tag 无计数字段。免登录 `GET /api/shorturlinfo` 只回 `view_visited` / `view_limit`
  （「浏览次数上限」的配置，不是统计）；带码分享回 `errno:-9`。网页/客户端「我的分享」里
  看得到浏览/保存/下载次数，但那是内部 web 接口 + BDUSS cookie。老 `/pcloud/feed/getsharelist` 已废。
- **替代**：GitHub Release 资产 `download_count` 公开免鉴权 —— 实测 v1.2.0 = **1012**、
  v1.1.0 = 998。⚠️ 要接进落地页就得先推翻「页面不连任何第三方接口」这条约定（v1.1.0 起就有），
  或自建构建期取数的代理 —— **没动**，等 ling 说。

**踩坑提醒**：夸克对不存在的路径回 `{"status":404,...,"No message available"}`，跟乱路径一样，
所以判「路径是不是真接口」必须**同时探一个乱路径对照**（真接口缺参数时报错形态不同）。
