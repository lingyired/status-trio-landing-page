## Native Icon Semantics

The implementation follows the frozen `v1.7.4` source:

- Center priority is connection-slot battery percentage, then eligible input
  source, then selected connected Bluetooth audio, then Ethernet/Wi-Fi.
- Bluetooth warning priority includes `notAssociated`, `off`, `noInternet`,
  and unavailable/offline behavior.
- A network-warning-suppressed input source falls through to Bluetooth when a
  selected connected Bluetooth output qualifies.
- Volume dot buckets use `ceil(percent / 25)`: 1-25 -> 1, 26-50 -> 2,
  51-75 -> 3, 76-100 -> 4. Muted or zero -> 0. The continuous arc preserves
  full 0-100 progress and keeps mute separate.
- Light/regular/bold ring scale is 1/1.25/1.5, shared by battery and volume
  presentation. The battery-gap mask scales with the visible ring.
- Bluetooth blue volume follows the selected connected Bluetooth output and
  nonzero volume, not playback.
- The plugged-in connection symbol participates in the indicator gap.
- Ethernet uses the frozen native geometry: two chevron paths and three dots,
  with the native stroke width and dot radius at scale 1. It is hidden by
  higher-priority center content.
